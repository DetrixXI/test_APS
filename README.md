# Test_APS

## Краткое описание
Реализован простой полнотекстовый поиск с помощью `ElasticSearch`, данные хранятся в `SQLite`.
Для доступа к данным созданы две ручки на `FastAPI`, работа с БД ведется с помощью `SQLALchemy`.
Имеется возможность развернуть сервис в контейнере `Docker`

## Стек

- **Python**
- **SQLite + Alembic + SQLAlchemy** - БД
- **Elasticsearch** - индекс на эластике
- **Docker + Docker Compose** - контейнеры

## Гайд по поднятию

1. Запускаем `Docker`
2. Переходим в ту директорию, куда был скачан репозиторий
3. В консоли набираем команду `docker-compose up --build`
4. Для тестов - `docker-compose --profile test up tests`
5. Готово
После запуска и прогрузки, сервис будет доступен по адресу 127.0.0.1:8000.

Интерактивная документация - Swagger UI: http://127.0.0.1:8000/docs

## API

### Поиск
```
GET test_task/search?query=
```
- 'query' - текстовый запрос, по которому осуществялестя поиск
Ответ:
```json
{
  "results": [
    {
      "text": "текст документа",
      "created_date": "2019-03-26T20:08:11",
      "rubric_codes": [
        "VK-1",
        "VK-4",
        "VK-8"
      ],
      "id": 62
}
```
### Удаление
```
DELETE test_task/test_task/del_by_id?id=
```
- `id` - id документа, который необходимо удалить. 
Ответ:
```json
{
  "results": True
}
```
 успешное удаление;

- `404 Not Found` - документ не найден
